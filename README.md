# درس‌یار | DarsYar

یک اپلیکیشن Flutter فارسی و راست‌چین برای برنامه‌ریزی درسی و ثبت پاسخ آزمون‌ها.

## امکانات فعلی

- داشبورد پیشرفت وظایف درسی
- افزودن، ویرایش، تکمیل و حذف وظایف با ذخیره‌سازی محلی
- برنامه هفتگی مطالعه با انتخاب روز، ساعت شروع و مدت جلسه
- علامت‌گذاری جلسه‌های مطالعه به‌عنوان انجام‌شده و نمایش مجموع دقیقه‌های برنامه روزانه
- نمای کلی هفت روز با تعداد جلسات، دقیقه‌های برنامه‌ریزی‌شده و پیشرفت هر روز
- ویرایش جلسه‌های مطالعه و جلوگیری از هم‌پوشانی زمان جلسات در یک روز
- گزارش هفتگی مجموع دقایق برنامه‌ریزی‌شده، دقایق تکمیل‌شده و درصد پیشرفت
- کپی جلسه‌های یک روز به روز دیگر با بررسی تداخل ساعت‌ها و بازنشانی وضعیت انجام‌شدن
- ساخت چند پاسخ‌برگ مستقل با نام اختصاصی
- انتخاب تعداد سؤال هر آزمون از ۱ تا ۲۰۰
- ثبت پاسخ‌های الف، ب، ج و د و علامت‌گذاری برای مرور
- ثبت کلید صحیح و نمایش پاسخ‌های درست، غلط، بی‌پاسخ و درصد
- زمان‌سنج آزمون با زمان‌های ۱۵، ۳۰، ۴۵ و ۶۰ دقیقه، توقف موقت و شروع مجدد
- ذخیره تاریخچه نتایج آزمون‌ها، میانگین درصد و نمودار روند ۷ نتیجه اخیر
- ذخیره خودکار پاسخ‌برگ‌ها روی دستگاه
- پشتیبانی از پوسته روشن، تیره و تنظیم دستگاه
- ساخت نسخه پشتیبان JSON از وظایف، برنامه مطالعه، پاسخ‌برگ‌ها و نتایج آزمون‌ها
- بازیابی نسخه پشتیبان پس از اعتبارسنجی قالب و تأیید جایگزینی اطلاعات
- انتقال خودکار داده‌های پاسخ‌برگ نسخه تک‌آزمونی قدیمی به ساختار چندآزمونی

## اجرا در محیط توسعه

نیازمندی‌ها: Flutter stable و Dart سازگار با نسخه درج‌شده در pubspec.yaml.

    flutter pub get
    flutter analyze
    flutter test
    flutter run

## ذخیره‌سازی و حریم خصوصی

اطلاعات وظایف، جلسه‌های برنامه هفتگی، نتایج و پاسخ‌برگ‌ها با shared_preferences روی همان دستگاه ذخیره می‌شوند. برای انتقال داده‌ها، در بخش تنظیمات «ساخت نسخه پشتیبان و کپی JSON» را انتخاب کن و متن کپی‌شده را در یک فایل متنی امن ذخیره کن. برای بازیابی، متن کامل JSON را در بخش «بازیابی از متن JSON» جای‌گذاری کن؛ قالب قبل از جایگزینی اطلاعات بررسی می‌شود و بازیابی به تأیید نیاز دارد. فایل پشتیبان را محرمانه نگه دار، چون شامل اطلاعات درسی و پاسخ‌هاست. در نسخه فعلی همگام‌سازی ابری یا حساب کاربری وجود ندارد؛ پاک‌کردن داده‌های برنامه می‌تواند اطلاعات ذخیره‌شده را حذف کند.

## وضعیت بررسی

GitHub Actions برای اجرای خودکار تحلیل کد و تست‌ها پیکربندی شده است. تا زمانی که یک اجرای موفق در بخش Actions ثبت نشده باشد، نباید وضعیت build یا تست را موفق فرض کرد.
